# Marca y contenido social

La pieza debe ser útil por sí misma, con español rioplatense claro y una idea concreta sobre IA, agentes, automatización o productividad. Evitá promesas absolutas, urgencia artificial y jerga sin explicación.

Facebook admite contexto y un cierre conversacional. Instagram debe ser más visual y breve, con pocos hashtags relevantes. Las dos captions deben estar adaptadas, no ser copias idénticas.

El recurso visual debe ser legible en móvil, respetar áreas seguras, usar nombres portables y llevar un texto alternativo descriptivo. No reutilices automáticamente una imagen o tema dentro de la ventana de frescura.


## Carruseles y tarjetas

Usá `metodo` cuando una persona necesite seguir una secuencia: portada con el problema y una lámina por cada paso. Debe haber entre 2 y 6 pasos; cada lámina explica una sola acción, con palabras corrientes y un ejemplo o criterio observable.

Usá `tarjetas` cuando el lector deba comparar o tener a la vista elementos del mismo nivel. La lámina acepta exactamente 2, 4 o 6 tarjetas: dos para contrastar, cuatro para un marco operativo y seis para una lista breve. Cada tarjeta contiene un título corto y una explicación autónoma. No se permite usar 3, 5 ni más de 6, porque compromete la legibilidad móvil.

Ambos formatos conservan el pie de compartir de MR Agentes. Una imagen de stock o generada puede aportar sólo el fondo; el archivo publicado debe ser el render final de una plantilla de marca.
