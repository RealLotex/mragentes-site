# Quality gates

Antes de preparar el cambio Git, exigí:

- front matter version 1 cerrado, `draft: false` e identidad única;
- 2 o 3 noticias reservadas por la misma ejecución y luego consumidas en el mismo cambio;
- URLs fuente HTTPS canónicas y enlaces críticos válidos;
- archivo Markdown portable y alias local si se conserva una URL anterior;
- imagen permitida, legible, optimizada, con hash y texto alternativo;
- contenido sustantivo, atribución y conclusión accionable;
- tests del dominio y build de Hugo verdes;
- manifiesto que enumere exactamente nota, asset y transición de cola.

Cualquier fallo cancela el cambio completo. No se habilitan efectos externos desde esta skill.
